**NoFences** is a powerful, open-source alternative to Stardock Fences for Windows. Organize your desktop icons into collapsible, customizable containers ("fences") to keep your workspace clean and productive.

![NoFences Banner](https://via.placeholder.com/800x300?text=NoFences+Desktop+Organizer)

## ✨ What's New in v2.5 (Innovative Update)

We've supercharged things with the **Internal Update**, introducing dynamic and interactive features:

*   **🎨 Magic Fences:** Fences automatically obtain the color of the content inside! (e.g. Blue/Purple for images, Green for documents, Orange for code).
*   **📂 Quick Import:** Right-click and choose **"Import Folder Content"** to instantly fill a fence with files from any directory.
*   **🕰️ Time Machine (Undo/Redo):** Mistakes happen. Press `Ctrl+Z` to undo renames, deletions, or file moves.
*   **🌬️ Breathing Effect:** A subtle, elegant animation pulses when new files land in a fence, letting you know the system is alive.
*   **📅 Contextual Awareness:** Configure fences to appear only during work hours, on weekends, or when battery is low.
*   **⚡ Performance:** Optimized rendering engine prevents lag even when resizing large fences.

## 🚀 Key Features

*   **Drag & Drop:** Easily drag files into fences.
*   **Minify/Roll-up:** Double-click or middle-click fence headers to collapse them into a tiny bar.
*   **Customization:** Full control over colors, fonts, transparency, and sizes.
*   **Smart Sorter:** Automatically categorize new files into specific fences based on rules.
*   **Desktop Integration:** Feels like a native part of Windows.

## 🛠️ Installation

1.  Download the latest release from the [Releases](https://github.com/Notbanzz/NoFences/releases) page.
2.  Run `NoFences.exe`.
3.  Right-click the tray icon to create your first fence!

## 🎮 Controls

| Action | Shortcut |
| :--- | :--- |
| **Undo** | `Ctrl + Z` |
| **Redo** | `Ctrl + Y` |
| **Rename Fence** | `F2` |
| **Delete Item** | `Delete` key |
| **Explore Folder** | `Alt + Double Click` on fence |
| **Run All Exes** | `Ctrl + Double Click` (Use with caution!) |
